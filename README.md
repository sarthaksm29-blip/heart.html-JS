This project demonstrates a simple interactive favorite feature using HTML, CSS, and JavaScript. It displays a list of characters, each with a heart button that represents a favorite action. When a user clicks the heart button, JavaScript toggles a CSS class that changes the heart’s color and switches the icon between an outlined and a filled heart. This is achieved using event listeners, class toggling, and dynamic HTML updates. The project is beginner-friendly and helps in understanding DOM selection, event handling, and basic style manipulation through JavaScript.
